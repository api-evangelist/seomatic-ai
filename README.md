SEOmatic provides AI‑powered SEO agents that automatically fix, publish, and prove website changes. Their platform offers tools like SEO Agent, Local SEO, AI Visibility Tracker, Google Business Profile management, SEO Audit, and Programmatic SEO, serving small businesses, agencies, and B2B companies. Users can integrate via MCP Server Skills, Chrome extensions, WordPress plugins, and other solutions, with pricing plans starting at $99 per month.

**Areas:** SEO · AI · Marketing · Automation · SEOmatic

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for SEOmatic: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
